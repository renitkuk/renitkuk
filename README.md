streamline the tendering process.

### ✨ Features

- 🔐 Admin & Vendor authentication
- 📋 Tender creation and management
- 🔎 Tender browsing
- 💰 Online bid submission
- 🗄️ SQL Server database integration
- ⚙️ Flask-based backend
- 🌐 Interactive web interface
